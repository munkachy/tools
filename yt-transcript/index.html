Transcript Grabber

Get a YouTube video's transcript as plain text, grouped into 5-minute blocks, ready to paste into Claude or any other AI.

Method 1 · Easiest

The bookmark button

  1. Drag this button to your browser's bookmarks bar:
    📜 Get Transcript
  2. Open any YouTube video on a computer and click the bookmark.
  3. A box appears with the transcript. Click Copy for AI and paste it into your chat.

Can't drag it? Right-click the button, copy the link, make a new bookmark, and paste the link as its address. Bookmarks like this run on desktop browsers, not in phone apps.

Method 2 · Always works

Paste and clean

  1. On the YouTube page, open the description and click Show transcript.
  2. Select all the transcript text in the side panel, copy it, and paste it below. (Caption files in .vtt or .srt format also work.)
Method 3 · On your computer

Python scripts

If you have Python, these download the transcript by themselves. Get them from the repository.

Main script (the one that worked in testing). It tries several ways in, because YouTube often blocks one but not another:

pip install -U yt-dlp
python yt_transcript.py "https://www.youtube.com/watch?v=VIDEO_ID"

Backup script, using a different library:

pip install -U youtube-transcript-api
python backup_transcript_api.py "https://www.youtube.com/watch?v=VIDEO_ID"

Add --plain to either one to leave out timestamps. On a Mac, add | pbcopy to the end of the command to copy the output straight to your clipboard.
