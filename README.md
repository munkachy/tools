# tools

Small personal tools.

- **[Transcript Grabber](yt-transcript/)**: get a YouTube transcript as clean, AI-ready text. Web page: https://munkachy.github.io/tools/yt-transcript/
- **[St. Bernard Happenings](newspaper/)**: the school newspaper viewer embedded on stbernardprep.com. Paste `newspaper/embed.html` into the page once; new issues are added with `newspaper/add-issue.sh` and show up automatically, with older ones in the archive.
